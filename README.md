# 「神人音效轮盘」Android 版（Shizuku 虚拟麦克风版）

SR Voiceover Roulette 的 Android 原生移植版（当前版本：`A-0.1.27-ShizukuMic`），支持 Android 8.0 及以上系统（Shizuku 虚拟麦克风与穿透热区建议 Android 12+，推荐 Android 13+）。

支持应用内三圈轮盘与无限自定义轮盘组、跨应用悬浮轮盘、Shizuku 免 Root 虚拟麦克风推流、零拦截穿透热区与游戏截图 1:1 对齐，并可自由导入本地音频、创建播放集及调整音量增益、变调与播放速度。

## 核心功能

- **Shizuku 免 Root 虚拟麦克风**：通过 Shizuku 注册 `REMOTE_SUBMIX` 系统音频通道，以 10 ms 低延迟将音效送入游戏/通话语音；优先走 `Shizuku.newProcess()` 直连通道并在异常时自动回退，附带 8 秒连接超时保护、`MODIFY_AUDIO_ROUTING` 权限诊断与精简规则兼容兜底；支持大体积/无损音频（10 MB+ FLAC/WAV）稳定流式解码、关闭本机监听时直通虚拟麦免 `MediaPlayer` 双重解码与零 GC 热循环推流；支持「常驻纯音效」「仅放音效时自动接管（1 秒连播保活）」「常驻 + 混入真麦（实验性）」三种模式、本机同时监听与独立音量调节。
- **一键关闭调试与后台**：在虚拟麦克风页提供「关闭调试与后台」按钮，退出前可一键停止虚拟麦、穿透热区、关闭无线调试并结束 `shizuku_server`，不常驻后台。
- **三圈轮盘与多轮盘组管理**：每组支持 8 个音效槽位（内圈 4 + 中圈 4），第三圈外环提供「上一组」「取消当前播放（中间双格合并）」「下一组」快捷手势；支持顶部左右切换、不限数量新增/删除轮盘组与自定义组名；提供「轮盘大小」「中空比例」「第三圈厚度」实时调节，主界面与悬浮轮盘同步所见即所得。
- **零拦截穿透热区 + 截图 1:1 对齐**：支持自由拖拽缩放矩形热区、导入游戏截屏作为 1:1 键位对齐底图、开启 Shizuku 底层零拦截穿透（不遮挡不吞触控），并支持隐藏热区边框。
- **丰富播放与音效参数**：内置 30 段演示音效，支持批量导入音频、播放集（独立默认参数、顺序 / 随机 / 随机不重复、单次播放数量与再次触发打断控制）、0%–200% 音量增益、固定/随机/连续变调变速。

## 安全说明

- 虚拟麦克风基于 Android 系统音频路由机制实现，纯本地处理音频，**不注入游戏进程、不修改游戏内存、不读取游戏数据**。
- 穿透热区仅通过 Shizuku 监听屏幕触摸坐标并触发本地音效播放，不模拟或篡改点击操作。
- 不同游戏的反作弊策略可能存在差异，且部分游戏会检测系统调试状态；不使用时建议点击「关闭调试与后台」彻底关闭无线调试与 Shizuku 服务。

## 构建

用 Android Studio 打开仓库根目录，安装 Android SDK Platform 36 和 Build-Tools 35.0.0，使用 JDK 17 和 Gradle 8.13 构建。命令行可执行：

```sh
gradle :app:assembleRelease
```

构建生成的 APK 会复制到 `DL/`（已在 `.gitignore` 中忽略）。
